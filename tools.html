// TOOL 01

Executor Daemon

実行デーモン

A small background program that runs on your computer and does the jobs the app delegates. Safely sandboxed, with a fixed vocabulary of about thirty actions.

  • Runs only what you approve
  • Open for audit, line by line
STATUS: IN DEVELOPMENT
// TOOL 02

Adapters

アダプター

Connectors that let the hub talk to local model runners and hosted AI services through one standard interface. Adding a provider means writing one small file.

  • One interface for every backend
  • New providers welcome upstream
STATUS: IN DEVELOPMENT
// TOOL 03

Benchmark DB

ベンチマーク

A public record of how real models perform on real devices. Every number measured on hardware we had in hand, never estimated.

  • Measured, never estimated
  • Submit your own device's numbers
